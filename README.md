# AZ Dash

A Subway Surfers–style endless runner for studying the **AWS Certified Solutions Architect – Associate (SAA-C03)** exam.

A question rolls in, then three gates come toward you — one per lane (`1a`, `1b`, `1c`). Switch lanes and run through the gate with the right answer. Jump the yellow **503** hurdles and dodge the red **429 THROTTLED** blocks.

## Play

**Play online:** https://bhonepyae-kyaw.github.io/merry-christmas-please-study/

It's a single static file with no build step. Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 8000
# then open http://localhost:8000
```

## Features

- 70 built-in scenario questions across the four SAA-C03 domains: Security (30%), Resilience (26%), Performance (24%), Cost (20%)
- Each gate shows the correct answer plus 2 of 3 distractors, picked at random
- **Runner** mode (3 lives, obstacles) or **Study** mode (no obstacles, no lives)
- Three reading speeds: Chill, Normal, Exam day
- Streak multiplier up to ×5
- Explanation after every answer; a review list of missed questions at the end of each run
- Custom question sets generated by Claude from your own PDFs
- Best score and per-topic accuracy saved in `localStorage`, per question set

## Custom question sets from a PDF

Besides the built-in SAA-C03 set, you can turn any study PDF into a question set:

1. On the menu, choose **+ New set from a PDF**.
2. Pick a PDF (up to 24 MB), paste your [Anthropic API key](https://console.anthropic.com/settings/keys), and choose how many questions to write (70 by default). You can also add an optional focus, such as "chapters 3–5".
3. Choose **Generate questions**. Claude (`claude-opus-5-5`) reads the PDF and writes scenario-style questions in the gate format: a short correct answer, three plausible wrong answers, and an explanation. It also groups them into 2–4 topics.
4. The set is saved in your browser, next to the built-in one. Switch between sets on the menu; each set keeps its own best score and per-topic accuracy. Up to 8 custom sets are kept.

How it works and what it costs:

- The page calls the Claude API directly from your browser with your key. There is no server. The PDF and key go only to `api.anthropic.com`.
- "Remember the key in this browser" stores the key in `localStorage`. Leave it unchecked on shared computers.
- Usage is billed to your Anthropic account. A typical 30–60 page PDF with 70 questions costs well under $2.
- If the safety classifier declines a request, the API's server-side fallback retries it on Anthropic's recommended fallback model.

## Adding built-in questions

Questions live in the `QUESTIONS` array near the top of the `<script>` in `index.html`:

```js
{d:"sec", q:"Scenario text?", a:"Correct answer", w:["Wrong 1","Wrong 2","Wrong 3"], e:"Why the answer is right."}
```

`d` is one of `sec`, `res`, `perf`, `cost`. Keep answers short (about 30 characters) so they fit on the gates.
